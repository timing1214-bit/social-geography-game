# 세계 지형 탐험 슈팅 게임 (World Geography Exploration Shooting Game)

사회 수업용 인터랙티브 세계 지형 탐험 비행 슈팅 웹 게임입니다.

## 기능 및 특징
- **지형 퀴즈 & 비행 슈팅 액션**: 다양한 세계 지형(산맥, 고원, 평야, 사막, 피오르 등)에 관한 문제를 풀고 적기를 격추하는 학습형 웹 게임
- **반응형 UI & 웹 표준**: 모바일 및 데스크톱 모두 지원
- **Tailwind CSS & Canvas 기반 렌더링**

## 실행 방법
웹 브라우저에서 `index.html`을 열거나 배포된 링크를 통해 접속하여 바로 플레이할 수 있습니다.
